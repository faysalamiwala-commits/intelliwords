# IntelliWords
Where Intelligence Meets Words.

IntelliWords is an open-source publishing house toolkit for people who want to make books worth reading.

## What we do?
- Help writers write books in English
- Format books for Amazon KDP
- Design book covers
- Help Pakistani writers earn $2000 monthly from books

## Our Mission
From Idea to Next Reader.

Made in Pakistan, for Global Readers.
